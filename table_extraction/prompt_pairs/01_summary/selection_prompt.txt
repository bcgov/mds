You are given a JSON array of tables already extracted from an annual mining reclamation report.

Task:
Select tables most likely to contain high-level report summary values.

Use only the provided tables. Do not infer from outside knowledge.

What to look for:
- Tables with company, mine name, permit number, report year, and next plan update date.
- Tables with high-level totals for disturbance area, reclaimed area, revegetated area, exempt area.
- Tables with mining production, milling production, and liability estimate.
- Tables that show the same summary fields for both current and previous reporting periods.
- Captions/subtitles and footnotes that indicate reporting period, units, or summary scope.

Selection rules:
- Prefer compact summary tables with explicit labels and numeric values.
- Prefer current-report values when both current and previous values exist.
- Keep tables that contain prior-report columns or rows when they also include the current summary fields.
- Use caption and footnote text as additional evidence for relevance.
- Do not prioritize detailed disturbance-category matrix tables unless they clearly provide direct high-level summary fields.
- Ignore unrelated, duplicate, low-quality, or narrative-only tables.

Return valid JSON only in this format:
{
  "selected_table_ids": ["..."],
  "selection_reasons": {
    "table_id": "short reason"
  },
  "notes": ["short caveats only"]
}

Rules:
- Output JSON only.
- Do not wrap in markdown.
- Do not include table values yet.
- If nothing matches, return an empty array.
