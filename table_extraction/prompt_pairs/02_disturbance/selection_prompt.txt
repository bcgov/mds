You are given a JSON array of tables already extracted from an annual mining reclamation report.

Task:
Select tables most likely to contain disturbance and reclamation matrix values.

Use only the provided tables. Do not infer from outside knowledge.

What to look for:
- Tables titled or structured like Summary of Areas Disturbed and Reclaimed.
- Grouped headers such as MINING AREA DISTURBED and RECLAMATION AREA RECONTOURED/SEEDED-PLANTED/FERTILIZED/REVEGETATED.
- Units in ha, disturbance-category rows, and a TOTAL row.
- Current-year and cumulative total columns.
- Captions/subtitles and footnotes that clarify period, units, or whether values are current versus cumulative.

Selection rules:
- Strongly prefer disturbance/reclamation matrix tables with explicit totals.
- Prefer current-report columns when both current and previous report values exist.
- Include tables with row-level disturbance categories (Administrative area/building, Other, Pit, Road, Stockpile, Tailings Storage Facility, Waste Dump).
- Use caption and footnote text as supporting evidence for table relevance.
- Ignore unrelated, duplicate, low-quality, or narrative-only tables.

Return valid JSON only in this format:
{
  "selected_table_ids": ["..."],
  "selection_reasons": {
    "table_id": "short reason"
  },
  "notes": ["short caveats only"]
}

Rules:
- Output JSON only.
- Do not wrap in markdown.
- Do not include table values yet.
- If nothing matches, return an empty array.
